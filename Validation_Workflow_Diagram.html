Workflow Overview:

This workflow automates the validation of Snooz tools by downloading PSG files from a private repository, extracting tool definitions from the Snooz installer, and adapting their JSON files to define inputs, outputs, and required parameters. The JSON modification process remains compatible with future CEAMS package versions.

Snooz is then executed with each tool individually. The generated outputs are compared against a gold-standard private repository, and a status file is saved as an artifact to record exactly which tools were executed, their versions, and the results of the output comparison.
